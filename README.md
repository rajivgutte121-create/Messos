# MessOS Android App

This is a free Android WebView wrapper for the existing MessOS website.

App name: MessOS
Website: https://rajivgutte121-create.github.io/Messos/

## Build free with GitHub Actions
1. Upload this project to a GitHub repository.
2. Push the `.github/workflows/build-apk.yml` workflow.
3. Open GitHub -> Actions -> Build MessOS APK.
4. Download the APK artifact from the completed workflow.

The app keeps JavaScript, DOM storage, file chooser, Supabase HTTPS access, Android back navigation and external-link handling enabled.
